Politica de Privacidade

Esta politica explica, de forma objetiva, como a beta publica do {{ app_display_name }} coleta, usa e protege os dados dos usuarios durante esta fase de testes.

1. Quais dados sao coletados

Podemos coletar os dados informados no cadastro, as configuracoes escolhidas dentro do sistema e os lancamentos financeiros registrados pelo usuario durante o uso da beta.

2. Para que os dados sao usados

Os dados sao utilizados para permitir o login, manter o funcionamento da conta, salvar informacoes online, gerar relatorios, produzir backups e melhorar o produto com base no uso real desta fase beta.

3. Armazenamento e seguranca

Os dados da beta podem ser armazenados em servidor online do projeto. Adotamos medidas razoaveis de seguranca, como protecao de acesso e cuidado com senhas, mas a versao beta ainda esta em validacao e pode passar por ajustes tecnicos.

4. Compartilhamento com terceiros

Os dados nao sao vendidos. Eles podem ser tratados apenas por servicos tecnicos necessarios para hospedagem, banco de dados, infraestrutura e operacao da plataforma beta.

5. Direitos do usuario

O usuario pode solicitar esclarecimentos, atualizacao de dados ou exclusao da conta beta entrando em contato pelo e-mail {{ support_email }}.

6. Atualizacoes desta politica

Como esta e uma versao beta, esta politica pode ser atualizada para refletir melhorias no produto, ajustes operacionais ou novas etapas da publicacao.

7. Contato

Responsavel por esta beta: {{ company_name }}. Para suporte, duvidas ou solicitacoes relacionadas a privacidade, use o e-mail {{ support_email }}.
